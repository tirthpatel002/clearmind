# What are NVIDIA NemoClaw and OpenShell?


Query: `NVIDIA NemoClaw OpenShell personal AI agent` (Tavily advanced search, fetched 2026-10-30T14:27:34.190Z)



## Answer

The sources indicate that the NVIDIA NemoClaw stack for the OpenClaw agent platform allows users to install Nemotron models and the OpenShell runtime in a single command, adding privacy and security controls to autonomous AI agents. NemoClaw uses the NVIDIA Agent Toolkit software to optimize OpenClaw and installs OpenShell to provide an isolated sandbox for data privacy and security. It runs on dedicated platforms including GeForce RTX PCs, RTX PRO-powered workstations, DGX Station, and DGX Spark AI supercomputers. The sources also mention that NemoClaw is available now, while OpenShell is in early preview.
