# What do Tavily's search, extract, crawl and map APIs do?


Query: `Tavily API search extract crawl map endpoints` (Tavily advanced search, fetched 2026-10-30T14:27:41.871Z)



## Answer

The Tavily Web API offers a unified set of REST-based endpoints for AI agents to search the web, extract page content, crawl sites, map sitemaps, and run AI research tasks. The API is authenticated with a bearer API key and includes endpoints for Tavily Search, Tavily Extract, Tavily Crawl, and Tavily Map. Tavily Crawl is a graph-based website traversal tool that can explore hundreds of paths in parallel with built-in extraction and intelligent discovery. The API is used by over a million monthly users and is purpose-built to inject real-time, structured data into the context window of LLMs, making it ideal for AI agents and advanced AI applications.
