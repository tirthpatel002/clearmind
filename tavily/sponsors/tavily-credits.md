# How do Tavily API credits and pricing work?


Query: `Tavily API credits pricing per request basic advanced` (Tavily basic search, fetched 2026-10-30T14:27:47.490Z)



## Answer

For Tavily API, each basic search request costs 1 API credit, while each advanced search request costs 2 API credits. For Tavily Extract, every 5 successful URL extractions cost 1 API credit for basic extract and 2 API credits for advanced extract. For Tavily Map, the cost depends on the number of pages mapped and whether natural-language instructions are specified, but you never get charged if a map request fails. Additionally, Tavily offers 1,000 free API credits every month with pay-as-you-go pricing at $0.008 per credit, and monthly plans ranging from $0.0075 to $0.005 per credit.
