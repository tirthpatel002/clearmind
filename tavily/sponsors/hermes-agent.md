# What is Hermes Agent?


Query: `Hermes Agent open source personal AI agent` (Tavily basic search, fetched 2026-10-30T14:27:36.984Z)



## Answer

Hermes Agent is an open-source AI agent from Nous Research that can remember context across sessions, use tools, run scheduled jobs, connect to channels like Telegram and Discord, and work from the terminal, dashboard, or hosted cloud surface. The official source repository is github.com/NousResearch/hermes-agent. It is fully open source under the MIT license, allowing users to fork, modify, and self-host it commercially. Hermes Agent features a learning loop for skill creation and memory management, supports multiple communication platforms, and includes a built-in cron scheduler for automated tasks.
