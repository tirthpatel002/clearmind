# What is the LoCoMo benchmark and what does it measure?


Query: `LoCoMo benchmark long conversation memory` (Tavily basic search, fetched 2026-10-30T14:27:59.702Z)



## Answer

The LoCoMo benchmark evaluates long-term memory in models through question answering, event summarization, and multi-modal dialogue generation tasks. It generates very long-term conversations using a machine-human pipeline that leverages LLM-based agent architectures and grounding dialogues on personas and temporal event graphs. The benchmark consists of ten annotated conversations for question-answering and event-summarization tasks, and the dialogues can be used for multimodal-dialog-generation tasks. The dataset is released on GitHub and includes a paper detailing the methodology and findings.
